GitHub Repositories for Reinforcement Learning

This document provides a list of useful GitHub repositories and resources for the topics covered in Week 1: Reinforcement Learning (Introduction).

 Q-Learning

    [omerbsezer/Reinforcement_learning_tutorial_with_demo](https://github.com/omerbsezer/Reinforcement_learning_tutorial_with_demo): A comprehensive tutorial on various reinforcement learning algorithms, including Q-learning, SARSA, and Policy Gradients.
    [ML-For-Beginners/8-Reinforcement/1-QLearning](https://github.com/microsoft/ML-for-Beginners/tree/main/8-Reinforcement/1-QLearning): A beginner-friendly introduction to reinforcement learning and Q-learning from Microsoft.
    [ronanmmurphy/Q-Learning-Algorithm](https://github.com/ronanmmurphy/Q-Learning-Algorithm): A Python implementation of a Q-learning agent that learns to navigate the "FrozenLake" environment.
    [jihoonerd/Deep-Reinforcement-Learning-with-Double-Q-learning](https://github.com/jihoonerd/Deep-Reinforcement-Learning-with-Double-Q-learning): An implementation of the Double DQN algorithm.

 Policy Gradients

    [Riashat/Policy-Gradient-Reinforcement-Learning](https://github.com/Riashat/Policy-Gradient-Reinforcement-Learning): Code for various actor-critic policy gradient methods, including Episodic REINFORCE, Stochastic Policy Gradient, and Deterministic Policy Gradients.
    [Finspire13/pytorch-policy-gradient-example](https://github.com/Finspire13/pytorch-policy-gradient-example): A concise example of a Policy Gradient implemented in PyTorch for the CartPole-v0 environment.
    [cuhk-ml-course/reinforcement-learning-tutorials](https://github.com/cuhk-ml-course/reinforcement-learning-tutorials/blob/master/02-policy-gradient.ipynb): A tutorial on the fundamental concepts of on-policy learning.
    [JamesChuanggg/Policy-Gradients-in-Reinforcement-Learning](https://github.com/JamesChuanggg/Policy-Gradients-in-Reinforcement-Learning/blob/master/Policy%20gradients.ipynb): A repository that explains the differentiability requirement for policy gradients and the on-policy, model-free, and offline nature of REINFORCE.
