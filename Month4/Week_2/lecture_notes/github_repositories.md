GitHub Repositories for Advanced Computer Vision

This document provides a list of useful GitHub repositories and resources for the topics covered in Week 2: Advanced Computer Vision.

 Transfer Learning

    Keras Documentation: Transfer Learning & Fine-Tuning: The official Keras guide to transfer learning.
    [https://keras.io/guides/transfer_learning/](https://keras.io/guides/transfer_learning/)
    Transfer Learning with ResNet50 in Keras: A tutorial on fine-tuning a ResNet50 model with a custom dataset.
    [https://github.com/suvo-de/Transfer-Learning-with-ResNet50-in-Keras](https://github.com/suvo-de/Transfer-Learning-with-ResNet50-in-Keras)
    Simple Transfer Learning with Keras: A straightforward implementation of transfer learning using the VGG16 model.
    [https://github.com/topics/transfer-learning-keras](https://github.com/topics/transfer-learning-keras)

 Object Detection

    Ultralytics YOLO: The official repository for the popular YOLO object detection models.
    [https://github.com/ultralytics/yolov5](https://github.com/ultralytics/yolov5)
    Object detection (YOLO) with PyTorch, OpenCV, and Python: A repository with code for an object and face detector based on YOLOv3.
    [https://github.com/computervisioneng/object-detection-yolo-opencv](https://github.com/computervisioneng/object-detection-yolo-opencv)
    Faster R-CNN implementation in Keras: A Keras implementation of the Faster R-CNN object detection algorithm.
    [https://github.com/kbardool/keras-frcnn](https://github.com/kbardool/keras-frcnn)

 Semantic Segmentation

    PyTorch U-Net for Semantic Segmentation: A PyTorch implementation of the U-Net model for semantic segmentation.
    [https://github.com/usuyama/pytorch-unet](https://github.com/usuyama/pytorch-unet)
    Semantic Segmentation on Satellite images using U-Net: A project that illustrates how to implement semantic segmentation on satellite images.
    [https://github.com/ketan-badhe/Semantic-Segmentation-on-Satellite-images-using-U-Net](https://github.com/ketan-badhe/Semantic-Segmentation-on-Satellite-images-using-U-Net)
    Awesome Semantic Segmentation: A curated list of semantic segmentation resources.
    [https://github.com/mrgloom/awesome-semantic-segmentation](https://github.com/mrgloom/awesome-semantic-segmentation)
