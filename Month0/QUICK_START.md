Month 0 Quick Start Guide

🚀 Start Here!

Welcome to Month 0: Essential Foundations! This quick guide gets you started in 5 minutes.

❓ Do You Need Month 0?

✅ YES, Take Month 0 If:
- You've never programmed before
- You're unsure about your math skills
- You want to feel confident and comfortable
- You have 4 weeks to build foundations
- You're new to AI/ML and want solid basics

- You write Python regularly
- You understand linear algebra and calculus

📖 Week Structure (Repeat Each Week)

Monday-Tuesday: Learn (2 hours)
1. Read the lecture notes completely
2. Run all code examples
3. Understand the "Why" behind concepts
4. Note down questions

Wednesday-Thursday: Practice (2-3 hours)
1. Complete Easy exercises (30 minutes)
2. Complete Medium exercises (45 minutes)
3. Challenge yourself with Hard exercises (45 minutes)
4. Solve your own mini-problems

Friday-Weekend: Project (2 hours)
1. Complete the weekly assignment
2. Test your code thoroughly
3. Make it look professional
4. Reflect on what you learned

🆘 Quick Troubleshooting

"I'm stuck on an exercise"
1. Review the relevant lecture section
2. Check the cheatsheet for examples
3. Look up the error on Google
4. Ask in a Python/coding forum
5. Try a simpler version of the problem first

"I don't understand the math"
1. Reread the explanation slowly
2. Watch the Khan Academy video (links provided)
3. Work through the example step-by-step
4. Try to explain it to someone else
5. Skip ahead and come back later

"This is taking too long"
1. That's normal! Learning takes time
2. You don't need to do ALL exercises
3. Focus on understanding, not completion
4. Quality > Quantity
5. Take breaks and rest

"I'm feeling confident, can I skip?"
1. You can skip ahead sections
2. But do the assignments!
3. Come back to exercises if unsure
4. Skipping too much might hurt later

📝 Success Tips

✅ DO:
- ✅ Type code instead of copy-pasting
- ✅ Run code frequently (after every few lines)
- ✅ Read error messages carefully
- ✅ Experiment and break things intentionally
- ✅ Take notes on confusing concepts
- ✅ Complete the assignments
- ✅ Review previous weeks

❌ DON'T:
- ❌ Just read without coding
- ❌ Copy code from examples
- ❌ Skip the assignments
- ❌ Rush through material
- ❌ Ignore error messages
- ❌ Move on when confused
- ❌ Compare your pace to others
