Week 2: Exercises - Control Flow & Functions

Complete these exercises to reinforce control flow and function concepts.

🟢 Easy Exercises

Exercise 1: Simple If-Else

Write a program that:
1. Gets a number from the user
2. Prints "Even" if it's divisible by 2, else "Odd"

Exercise 2: Grade Converter

Create a program that:
1. Gets a numerical score (0-100)
2. Prints the corresponding letter grade (90+ A, 80+ B, etc.)

Exercise 3: Simple Loop

Write a program that prints numbers 1 through 10 using a for loop.

Exercise 4: List Sum

Create a program that:
1. Creates a list of 5 numbers
2. Calculates the sum
3. Prints the result

Exercise 5: Simple Function

Write a function that takes a name and returns a greeting string.

🟡 Medium Exercises

Exercise 6: Temperature Alert

Create a program that:
1. Gets a temperature from user
2. Prints appropriate message based on temperature
3. Freezing (<32), Cold (32-50), Cool (50-65), Warm (65-80), Hot (80+)

Exercise 7: Factorial Function

Write a function that calculates factorial (n!):
- 5! = 5 × 4 × 3 × 2 × 1 = 120

Exercise 8: List Filter

Create a program that:
1. Takes a list of numbers
2. Filters out numbers less than 10
3. Prints the filtered list

Exercise 9: Password Strength Checker

Create a function that checks password strength:
- At least 8 characters: +1
- Contains uppercase: +1
- Contains numbers: +1
- Return a score 0-3

Exercise 10: Counter Function

Write a function that counts how many times a value appears in a list.

🔴 Challenge Exercises

Challenge 1: Multiplication Table

Create a function that prints a multiplication table (e.g., 7×1 to 7×12).

Challenge 2: Fibonacci Sequence

Write a function that generates Fibonacci numbers up to n terms.
- Sequence: 1, 1, 2, 3, 5, 8, 13, ...

Challenge 3: List Operations

Create functions for:
- Finding the maximum value
- Finding the minimum value
- Calculating average
- Removing duplicates

Challenge 4: Bank Account Simulator

Create functions to:
- Deposit money (add to balance)
- Withdraw money (subtract from balance)
- Check balance
- Display transaction history

📝 Mini-Project: Student Grade Manager

Create a program that:
1. Stores student names and grades in a dictionary
2. Has functions to:
   - Add a new student
   - Update a student's grade
   - Calculate class average
   - Find top performer
   - Display all students and grades
