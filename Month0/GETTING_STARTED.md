Month 0 Foundations - Complete Overview

🎉 Welcome to Month 0!

You've decided to build a strong foundation before diving into AI/ML. Excellent choice! This document provides a complete overview of what you'll learn.

📚 What is Month 0?

Month 0: Essential Foundations is a 4-week intensive program designed for complete beginners in both programming and mathematics. This month bridges the gap between zero experience and being ready for Month 1.

Who Should Take Month 0?

✅ Take Month 0 if you:
- Have never programmed before
- Haven't done math in years
- Want to feel confident before Month 1
- Are nervous about coding/math
- Have time to build proper foundations

❌ Skip Month 0 if you:
- Have solid Python experience
- Understand linear algebra and calculus already
- Are confident in your math skills
- Want to move quickly to AI/ML topics

Decision: Even if unsure, taking Month 0 is never wasted time!

🎯 Learning Philosophy

The 3-Step Learning Cycle (Per Week)

Step 1: Understand (2-3 hours)
- Read lecture notes carefully
- Work through examples
- Watch if videos are provided
- Ask questions on ambiguous concepts

Step 2: Practice (2-3 hours)
- Do the exercises
- Try before looking at solutions
- Debug your own code
- Experiment with variations

Step 3: Apply (1-2 hours)
- Complete the assignment
- Build something complete
- Reflect on what you learned
- Prepare for next week

Key Principles

1. Type, Don't Copy - Typing code builds muscle memory
2. Break Things - Intentionally write broken code to understand errors
3. Explain It - If you can explain it simply, you understand it
4. Repeat - Struggle a bit; that's learning happening
5. Connect - Link new concepts to things you already know

💡 Study Tips

Time Management
- Consistency > Duration - 1 hour daily beats 5 hours once
- Active Learning - Reading = passive, coding = active
- Breaks - 25 min focus + 5 min break = optimal
- Review - Spend 10% of time reviewing previous weeks

When Stuck
1. Read the error - Error messages tell you what's wrong
2. Google it - Most errors are common and answered
3. Debug systematically - Add print statements, test parts
4. Ask in forums - Include error, your code, what you tried
5. Sleep on it - Fresh mind often solves the problem

Mindset
- ✅ "I can learn this" (growth mindset)
- ✅ "Errors are learning" (debugging is learning)
- ✅ "Progress not perfection" (first try rarely perfect)
- ❌ "I'm not a math person" (incorrect belief)
- ❌ "This should be easy" (learning is hard by definition)
