1. Understand First - Build intuition before formulas
2. Practice Often - Repetition builds muscle memory
3. Apply Immediately - Connect to real-world examples
4. Reflect Regularly - Consolidate learning weekly
5. Build Confidence - Each week builds on previous

Scaffold Structure
- Top-down for each topic: big picture → details
- Progressive complexity: easy → medium → challenging
- Multiple formats: lecture notes, exercises, projects, cheatsheets
- Increasing independence: guided → scaffolded → independent
