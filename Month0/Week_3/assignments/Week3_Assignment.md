Week 3: Assignment - Data Analysis Project

📋 Project Overview

Conduct a complete statistical analysis on a dataset and create visualizations.

🎯 Part 1: Data Preparation (20%)

- Load or create a dataset (at least 50 data points)
- Clean any missing or invalid values
- Document the data source

🎯 Part 2: Statistical Analysis (40%)

Calculate and report:
1. Mean, median, mode
2. Standard deviation and variance
3. Min, max, range
4. Quartiles (Q1, Q2, Q3)

Interpret what these statistics tell you about the data.

🎯 Part 3: Visualizations (30%)

Create at least 4 different plots:
1. Histogram (distribution)
2. Box plot (quartiles and outliers)
3. Line plot (trends over time if applicable)
4. Scatter plot (relationships between variables)

🎯 Part 4: Insights & Report (10%)

Write a 1-2 page report explaining:
- What the data represents
- Key statistical findings
- Insights from visualizations
- Any patterns or anomalies

📤 Submission

Submit:
1. Python script with all analysis
2. Generated plots (as images)
3. Written report
