Week 3: Exercises - Essential Math Part 1

Practice problems for statistics, probability, and visualization.

🟢 Easy Exercises

Exercise 1: Calculate Mean
Write a program that calculates the mean of a list of numbers.

Exercise 2: Find Maximum and Minimum
Create a function that finds both max and min values in a list.

Exercise 3: Calculate Standard Deviation
Write code to calculate standard deviation (with formula given).

Exercise 4: Simple Plot
Create a line plot with matplotlib showing x²

Exercise 5: Histogram
Plot a histogram of random test scores (50-100).

🟡 Medium Exercises

Exercise 6: Data Statistics
Calculate mean, median, mode, and std dev for a dataset.

Exercise 7: Scatter Plot with Trend Line
Create a scatter plot and add a line showing the trend.

Exercise 8: Probability Simulation
Simulate flipping a coin 1000 times and plot results.

Exercise 9: Linear Regression Line
Plot data points and draw the best-fit line.

Exercise 10: Multiple Subplots
Create a 2x2 grid showing different visualizations.

🔴 Challenge Exercises

Challenge 1: Data Analysis Project
1. Load or create a dataset
2. Calculate all statistics
3. Create visualizations
4. Write summary report

Challenge 2: Probability Calculations
Calculate probabilities for:
- Coin flips
- Dice rolls
- Card draws
- Compound events

Challenge 3: Statistical Comparison
Compare two datasets visually and statistically.
