Week 4: Exercises - Essential Math Part 2

Practice problems for linear algebra and calculus concepts.

🟢 Easy Exercises

Exercise 1: Vector Creation and Operations
Create vectors and perform basic operations (addition, subtraction, scaling).

Exercise 2: Dot Product
Calculate dot products of vectors and interpret the results.

Exercise 3: Matrix Creation
Create matrices and access elements.

Exercise 4: Matrix Addition and Scalar Multiplication
Perform basic matrix operations.

Exercise 5: Numerical Derivative
Approximate the derivative of simple functions numerically.

🟡 Medium Exercises

Exercise 6: Matrix Multiplication
Perform matrix multiplication and verify results.

Exercise 7: Transpose and Determinant
Find transposed matrices and calculate determinants.

Exercise 8: Linear Transformation
Apply rotation and scaling transformations to vectors and visualize.

Exercise 9: Derivative Calculation
Calculate derivatives of polynomial functions.

Exercise 10: Gradient Computation
Compute gradients for multivariable functions.

🔴 Challenge Exercises

Challenge 1: Optimization Project
Implement gradient descent to find function minimum.

Challenge 2: Linear System Solver
Solve systems of linear equations using matrices.

Challenge 3: Geometric Transformation
Apply multiple transformations and visualize the results.

Challenge 4: Calculus Application
Use derivatives to find critical points and optimize functions.
